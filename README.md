# WONIO - Apple Design

## Schnell online bringen (2 Min)
1. Gehe auf netlify.com oder vercel.com
2. Drag & Drop den Ordner hier rauf ODER die Datei `wonio-apple-built.html` umbenennen zu `index.html` und hochladen
3. Fertig - Link hast du sofort für Sartorius

## Lokal in VS Code
npm install
npm run dev

## Inhalt
- App.tsx = Apple Design mit Dark/Light Mode
- index.css = Apple Farben #FFFFFF / #000000 + #0071E3
- wonio-apple-built.html = Fertige Seite zum direkt hochladen

Für Sartorius Gespräch: Einfach Link zeigen.
